Current Requirement

We already use External Secrets Operator (ESO) to synchronize secrets from HashiCorp Vault into Kubernetes Secrets.

The requirement is as follows:

A secret containing an API key is stored in HashiCorp Vault.

The secret should be retrieved from Vault through our existing External Secrets Operator integration.

The synchronized Kubernetes Secret should be referenced in the MICS UI Components Kubernetes Deployment YAML using an environment variable.

Our React application contains an index.ts file where an x-api-key value is currently defined or used.

Instead of hardcoding the API key in index.ts, I want the application to retrieve its value dynamically from the environment variable configured in the Kubernetes Deployment.

The solution should work with our existing React/Vite application architecture and GitOps deployment process.
